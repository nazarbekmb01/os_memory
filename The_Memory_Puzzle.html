Older method

Segmentation

A program is split into segments of different sizes, following its logical parts (code, data, stack). Each segment needs one continuous gap in RAM.

Problem: fragmentation. Gaps between segments become too small to use.

Modern method

Paging

A program is split into pages of equal size. RAM is split into frames of the same size. Any page fits in any free frame, so pages of one program can be scattered.

Like a car park where every space is the same size.

Virtual memory: when RAM is full, the OS keeps some pages on the disk and swaps them in when needed. Programs can be bigger than RAM. But every time a page is not in RAM there is a page fault: the OS must fetch it from the disk, which is thousands of times slower.

When RAM is full, which page should go back to disk? Two rules:

Rule 1

FIFO · First In, First Out

Swap out the page that has been in RAM the longest.

Rule 2

LRU · Least Recently Used

Swap out the page that has not been used for the longest time.

Disk thrashing: RAM is so full that the OS spends most of its time swapping pages between RAM and disk. Little useful work is done; the computer seems to freeze and the disk is busy all the time. Fixes: close programs, add more RAM.

    Glossary: key terms
    

      
Segmentation
A program is split into segments of different sizes (code, data, stack).

      
Fragmentation
Free memory is split into small gaps that are too small to use.

      
Paging
A program is split into pages of equal size that fit into frames.

      
Frame
A fixed-size block of RAM; one page fits in one frame.

      
Logical memory
The continuous memory a program thinks it has, with addresses from 0.

      
Page table
The OS's map from each page of a process to its frame (or the disk).

      
Virtual memory
Using disk space as an extension of RAM.

      
Page fault
A page is needed but is not in RAM, so it must be read from the disk.

      
Disk thrashing
So much swapping between RAM and disk that little useful work is done.

      
FIFO / LRU
Rules for which page to swap out: oldest in RAM / least recently used.
